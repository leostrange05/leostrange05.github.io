# :memo: 本站志

## 施工中

2026 年 2 月起，本站开始施工，到 2 月底基本形成了现在的装潢。

## 为什么叫“述真阁”？

“述真”二字与作者之名呼应，算是我为自己取的一个雅号。

## Fun Fact

本站基于 [:simple-materialformkdocs: Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)，由 :simple-googlegemini: Google Gemini 协同构建。你所看到的主页标题区域，很大程度上由 AI 辅助实现。你可以在 [本站的 :fontawesome-brands-github: GitHub 仓库](https://github.com/leostrange05/leostrange05.github.io) 查看源代码。

之所以选择 Material for MkDocs，是我在看到诸如 [:material-school: OI Wiki](https://oiwiki.org) 以及本系的计算机组成实验教程等站点后，被其简洁、清晰的设计风格所吸引。

    !!! warning "这是警告卡片"

主页底部的波浪形状来自 [Shape Divider](https://www.shapedivider.app/)。站点浅色模式的配色方案采用了 Solarized Light 的米黄色调，旨在减轻视觉疲劳。

[^1]: “卡片”并非官方术语，而是我个人对其样式的形象化称呼。官方文档中将其称为 “Admonitions”，意为“告诫”或“警告”。
